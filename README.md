# Lighthouse UIKit

Игровой web UIKit в стиле рисованной морской игры: маяки, акварельные заголовки, кремовые панели и объёмные кнопки. Собран по двум изображениям интерфейса с вниманием к композиции, формам и отдельным деталям референсов.

Текст, цены, статусы, вкладки и кнопки — самостоятельные HTML-компоненты. Они реагируют на действия, меняются под данные игры и растут вместе с содержимым. Иллюстрации, фон и акварельные мазки хранятся отдельными ресурсами.

В репозитории находятся готовый UIKit, интерактивное превью и скилл **reference-uikit**, который описывает процесс создания подобных наборов по изображениям.

## Что входит в UIKit

| Окно | Содержимое |
| --- | --- |
| **Achievements** | Строки достижений, иллюстрации, описания, выполненные и закрытые состояния |
| **Lighthouses & Equipment** | Вкладки коллекции, карточки маяков и оборудования, редкость и выбор предметов |
| **Daily Rewards** | Семь дней наград, серия посещений и состояния получения |
| **Upgrades** | Категории улучшений, уровни, характеристики, стоимость и баланс |
| **Build** | Слоты снаряжения, выбор предметов, характеристики и сохранение демонстрационной сборки |

Базовый набор включает кнопки, панели, карточки, бейджи, вкладки, модальные окна, уведомления, поля ввода, переключатели, ползунки, индикаторы прогресса и SVG-иконки.

### Оформление и адаптивность

- **Акварельные заголовки.** Прозрачная подложка отделена от надписи. Девятисегментная растяжка сохраняет форму краёв мазка, позволяя середине увеличиваться под текст.
- **Кнопки и рамки.** Скругления, обводки, верхние блики и нижние цветные кромки формируются стилями и сохраняют характер при изменении размеров.
- **Живой текст.** Заголовки, названия предметов и описания можно менять и переводить. Окна и строки учитывают переносы; в превью есть режим длинных подписей.
- **Несколько размеров.** Раскладка перестраивается под ширину контейнера. В превью можно менять ширину и проверять узкие экраны.
- **Локальные ресурсы.** HTML, CSS и JavaScript ES modules без обязательного фреймворка. Изображения и шрифты включены в проект.

В игровых окнах используется **DynaPuff**, в базовых компонентах — **Nunito**. **Lilita One** включён как альтернативная гарнитура. Лицензии находятся рядом со шрифтами в [assets/fonts](assets/fonts).

## Как создавался UIKit

1. **Разбор референсов.** Два изображения разделили на окна, повторяемые строки и карточки. Для каждого элемента выделили текст, поведение и художественное оформление: силуэты рамок, форму кнопок, мазки под заголовками, шрифты и иконки.
2. **Подготовка отдельных иллюстраций.** Из референсов извлекли изображения предметов и значки. У иллюстраций маяков удалили встроенные метки редкости, чтобы редкость отображалась отдельным элементом и могла меняться.
3. **Работа с ImageGen.** Восстановили фон гавани в местах, закрытых окнами, подготовили дополнительные иллюстрации и отдельный прозрачный мазок для заголовков. Для мазка сохранили форму концов и настроили растяжение средней части.
4. **Сборка компонентов.** Панели, кнопки, подписи, статусы и индикаторы сверстали на HTML/CSS. Затем из этих элементов собрали композиции обоих референсов и добавили интерактивные состояния.
5. **Сравнение с исходниками.** Уточняли пропорции окон, характер шрифта, акварельные подложки, форму кнопок и размер художественных элементов. Сходство оформления и работоспособность компонентов проверяли отдельно.
6. **Проверка поведения.** Проверили выбор предметов, вкладки, закрытие и восстановление окон, награды, улучшения, длинные тексты и повторное подключение компонентов. Браузерные проверки охватывают ширины 1528, 390 и 320 px.

Промпты и описание обработки изображений сохранены в [assets/PROMPTS.md](assets/PROMPTS.md). Происхождение спрайтов и координаты вырезок — в [assets/sprites/manifest.json](assets/sprites/manifest.json), параметры растяжения акварели — в [assets/header-brush.slices.json](assets/header-brush.slices.json).

## Скилл reference-uikit

[reference-uikit](skills/reference-uikit/SKILL.md) — инструкция для Codex по созданию игрового web UIKit из референсов. Она закрепляет подход, использованный в этом проекте: сначала разобрать визуальный язык, затем подготовить независимые ресурсы, собрать адаптивные компоненты и проверить их в превью.

Скилл помогает:

- сохранять композицию, типографику, формы и художественные детали исходного интерфейса;
- отделять иллюстрации и декор от текста, состояния и игровой логики;
- готовить акварельные подложки и рамки с растяжением по сегментам;
- применять ImageGen для конкретных недостающих ресурсов;
- проверять длинные подписи, узкие контейнеры, взаимодействия и комплектность выдачи;
- проверять пакет на служебные файлы, персональные пути и признаки секретов.

Внутри скилла:

| Файл | Назначение |
| --- | --- |
| [SKILL.md](skills/reference-uikit/SKILL.md) | Основной процесс работы по референсам |
| [paint-and-assets.md](skills/reference-uikit/references/paint-and-assets.md) | Акварель, отдельные ассеты, шрифты, кнопки и растяжение рамок |

Для использования скопируйте папку `skills/reference-uikit` в `~/.codex/skills/` и передайте Codex свои изображения. Пример запроса:

> Используй $reference-uikit: собери по этим изображениям точное превью и готовые растяжимые компоненты для интеграции в игру. Особое внимание — подложкам заголовков, формам кнопок и поведению при длинном тексте.

Скилл применим к разным визуальным стилям: оформление каждого нового UIKit определяется его референсами.

## Посмотреть и попробовать

Нужен Node.js 18 или новее; npm-зависимости устанавливать не требуется.

```sh
npm run build
npm run dev
```

Откройте `http://127.0.0.1:4173`:

- **Главная страница** — два игровых экрана и набор отдельных элементов. Можно переключать сцены, менять ширину, вводить длинный текст и пробовать состояния.
- **catalog.html** — каталог компонентов с примерами и песочницей.
- **examples/game.html** — небольшая игра, показывающая связь интерфейса с игровой логикой.

Сборка создаёт `dist/` и архив `lighthouse-uikit.zip` для переноса компонентов.

## Использовать в игре

Скопируйте `kit/` и нужные ресурсы из `assets/`, сохранив их взаимное расположение. Базовые стили подключаются из `kit/lighthouse.css`; оформление по референсам — из `kit/reference.css` и `kit/game-components.css`.

В [kit/game-ui.js](kit/game-ui.js) есть функции `renderAchievements`, `renderEquipment`, `renderDailyRewards`, `renderUpgrades`, `renderBuild` и `renderControls`. Они возвращают разметку отдельных окон, к которой можно подключить данные и обработчики своей игры. [kit/lighthouse.js](kit/lighthouse.js) содержит поведение базовых компонентов, а [kit/icons.js](kit/icons.js) — набор SVG-иконок.

`mountGameUI()` собирает интерактивное демо и хранит примерное состояние в памяти страницы. Его `onAction` вызывается после изменения этого состояния. Для настоящих покупок, наград и сохранения используйте собственную игровую логику; отдельные функции рендера позволяют оставить состояние под её управлением.
